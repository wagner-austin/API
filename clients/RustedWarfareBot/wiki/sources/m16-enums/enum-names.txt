Every enum in the pinned jar, by constant name
==============================================

Game: Rusted Warfare 1.15 (code 176, build #28), game-lib.jar.

Method: find every enum in the CFR decompile, then read its constant names out
of the class's own <clinit> with javap:

  javap -p -c -cp game-lib.jar <class> | grep '// String '

ProGuard renamed the enum FIELDS but not the name strings passed to the Enum
constructor, so `javap` recovers every constant name even where the decompile
shows only `a, b, c`. 53 enums, all of com.corrodinggames.*; the bundled
Steamworks enums were never obfuscated and are excluded.

Regenerable from the jar alone -- no running game, no live state.
