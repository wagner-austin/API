# survival rate on an identical specification, and seeding alone did not move

# first live tick and rebases traces to match age, so if the last noise
# source is truly closed, these twelve scorecards should be identical -- and
# any pair of differing rows is a measurement of what still varies.
#
#   make sweep SWEEP_JOBS=sweeps/noise-held.txt SWEEP_NAME=noise-held \
#     SWEEP_WORKERS=12 SWEEP_MATCH="maps/skirmish/[p2]duel_lake.tmx 1"
#
# Twelve in parallel is deliberate: it also certifies that CPU contention
# cannot leak into a held, locked match. Full length, because divergence
# compounds -- agreeing for 600 samples is not agreeing for 4,000.
