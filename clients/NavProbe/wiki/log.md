Unavoidable -- a model with nsensor=0 still fails, because Warp compiles the whole sensor module. Every measurement in this project therefore characterises the only mode available to MJWarp users. This is the most actionable thing found so far: a defect with a file, a line and a stated reason, fixable inside MuJoCo-Warp alone.
