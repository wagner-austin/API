# from the manifest, so a manifest edited to match a wrong file no longer
# agrees with anything. A record derived from the manifest would agree with it
# by construction and check nothing.

# exactly one field -- `arm` -- or the comparison they feed is confounded, and
# a digest per spec is what makes that checkable after the fact rather than
