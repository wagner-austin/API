# Certified corpus digests: Turkic BASE char-LSTM corpora (corpora_clean)
#
# The seven corpora that trained the base models in LSTM/checkpoints/, and
# that slurm/train_base.sub named before it was replaced by
# runs/sweep-turkic-bases.json.
#
# Verified before staging:
#   character counts checked against corpora_clean/cleaning_manifest.json,
#   which the cleaning run wrote at generation time and independently of any
#   staging. All seven match exactly:
#     az 12,639,050  fi 12,640,761  kk 12,626,196  ky 12,640,860
#     tr 12,629,197  ug 12,641,915  uz 12,642,807
#
# NO DIGEST RECORD EXISTED FOR THESE BEFORE NOW, which is worth stating
# plainly: the base models and the excess-CE matrices already published were
# trained on bytes nobody hashed. This record ANCHORS the corpus from here.
# It cannot retroactively verify what trained those models -- nothing can,
# for bytes never published before. Its value is that every later stage must
# match it, so a corpus regenerated from a different source state is refused
# rather than silently trained on.
#
# WHAT THESE CORPORA DO NOT RECORD, checked 2026-08-28. Their
# cleaning_manifest.json carries only the four cleaning parameters and the
# per-language counts. It does NOT carry a rules_fingerprint, so nothing says
# which transliteration rules produced them. The v3 rebuild's manifest DOES
# carry one -- eight entries, seven .rules files plus the symbol map.
#
# Checked against turkic-transliteration as it stands today:
#   the seven .rules files still match v3's recorded digests exactly;
#   symbol_map does NOT match, and does not match either of the two versions
#   in that repository's history, in any line-ending form. So v3 was built
#   against a symbol map that is not in version control, and v3 is therefore
#   not byte-reproducible from what exists today.
#
# The known-risky change to that map -- merging the U+02A6 ligature into
# t-U0361-s for Kyrgyz, committed 2026-08-12 with the note that "corpora
# published before then carry it" -- is NOT the discrepancy. Both corpora
# were checked directly: zero U+02A6 in either Kyrgyz file, 19,374 merged
# forms in the base set and 19,421 in v3. Whatever the symbol map difference
# is, it did not leave the ligature behind.
#
